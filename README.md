# 🏹 RobinCall P2P

**P2P-телефон для RobinHood. Бета-версия.**

Устанавливается как отдельное приложение на телефон через браузер (PWA). Работает полностью независимо: создаёт защищённые каналы связи и обеспечивает прямые голосовые звонки между пользователями без центрального сервера.

---

## Как установить

1. Откройте сайт на телефоне
2. Нажмите «Установить» или «Добавить на экран»
3. Приложение появится как иконка — можно звонить

---

## Как пользоваться

| Кнопка | Действие |
|--------|----------|
| 🏹 **Стрела** | Создать новый канал. Ссылка скопируется в буфер — отправьте другу |
| 📞 **Звонок** | Позвонить собеседнику (появляется когда канал активен) |
| 🔊 **Громкая связь** | Переключить динамик |
| ❌ **Завершить** | Повесить трубку |

---

## Как это работает

1. Нажмите 🏹 Стрела — приложение создаст защищённый канал
2. Отправьте ссылку другу
3. Когда друг откроет ссылку — канал активируется
4. Нажмите 📞 Звонок — установится прямой WebRTC-звонок
5. Говорите! Голос шифруется (DTLS-SRTP)

Если прямой P2P заблокирован — автоматически используется TURN-сервер.

---

## Технологии

| Компонент | Назначение |
|-----------|------------|
| **P2PPong** | Сигнальный сервер (маяки) |
| **WebRTC** | Прямая передача голоса |
| **Google STUN** | Определение внешнего IP |
| **Metered.ca TURN** | Резервный канал |
| **AES-256-GCM** | Шифрование сигнального канала |
| **DTLS-SRTP** | Шифрование голоса |
| **PWA** | Установка как нативное приложение |
