# 🏹 RobinCall P2P

**P2P-телефон для RobinHood. Бета-версия.**

Устанавливается как отдельное приложение на телефон через браузер (PWA). Работает полностью независимо: создаёт защищённые каналы связи и обеспечивает прямые голосовые звонки между пользователями.

Поддерживает две стрелы: Шервуда (Render) и Варп (Cloudflare Workers).

---

## Как установить

1. Откройте сайт на телефоне
2. Нажмите «Установить» или «Добавить на экран»
3. Приложение появится как иконка — можно звонить

---

## Как пользоваться

| Кнопка | Действие |
|--------|----------|
| 🏹 **Стрела** | Выбрать тип стрелы и создать канал |
| 📞 **Звонок** | Позвонить собеседнику |
| 🔊 **Громкая связь** | Переключить динамик |
| ❌ **Завершить** | Повесить трубку |

---

## Стрелы

| Стрела | Сервер | Скорость | Где работает |
|--------|--------|----------|--------------|
| 🏕️ **Шервуда** | Render | 2-6 сек | Везде |
| ⚡ **Варп** | Workers | <1 сек | С VPN/Amnezia |

---

## Технологии

| Компонент | Назначение |
|-----------|------------|
| **P2PPong** | Сигнальный сервер |
| **WebRTC** | Прямая передача голоса |
| **Google STUN** | Определение IP |
| **Metered.ca TURN** | Резервный канал |
| **DTLS-SRTP** | Шифрование голоса |
| **PWA** | Установка как нативное приложение |

---

## Условия использования

RobinCall является частью RobinHood P2P. На него распространяются все условия использования RobinHood P2P. Автор не несёт ответственности за использование RobinCall третьими лицами в любых целях.
