
Если прямой P2P заблокирован — автоматически используется TURN-сервер.

---

## Технологии

| Компонент | Назначение |
|-----------|------------|
| **WebRTC** | Прямая передача голоса |
| **Google STUN** | Определение внешнего IP |
| **Metered.ca TURN** | Резервный канал (если P2P заблокирован) |
| **DTLS-SRTP** | Шифрование голоса |

---

## Условия использования

RobinCall является частью RobinHood P2P. На него распространяются все условия использования RobinHood P2P.

Используя RobinCall, вы соглашаетесь с условиями RobinHood P2P. Автор не несёт ответственности за использование RobinCall третьими лицами в любых целях.
