# 🏹 RobinCall v1.0

**Автономный P2P-клиент для голосовых вызовов RobinHood P2P. Бета-версия.**

RobinCall позволяет совершать прямые аудиозвонки через сигнальный сервер P2PPong. Работает как самостоятельное приложение или в связке с RobinHood P2P.

Без регистрации, без серверов хранения данных. Только прямой WebRTC-звонок между двумя участниками.

---

## Как начать

1. Откройте RobinCall
2. Дождитесь статуса «Готов к вызову»
3. Нажмите кнопку вызова
4. Собеседник должен принять звонок в своём RobinCall (или RobinHood)
5. Разговаривайте!

---

## Особенности

- Прямой P2P аудиозвонок через WebRTC
- Шифрование DTLS-SRTP
- Авто-выбор STUN/TURN серверов
- Поддержка ICE-кандидатов с очередью (стабильнее на мобильных сетях)
- Проверка origin для защиты от подмены iframe
- Восстановление канала из sessionStorage
- Простой минималистичный интерфейс
- Совместимость с основным RobinHood P2P

---

## Технологии

| Компонент | Назначение |
|-----------|------------|
| **P2PPong** | Сигнальный сервер |
| **WebRTC** | Голосовые звонки |
| **DTLS-SRTP** | Шифрование медиа |
| **STUN/TURN** | Обход NAT |

## Условия использования

RobinCall является частью экосистемы RobinHood P2P. На него распространяются все условия использования RobinHood P2P. Автор не несёт ответственности за использование RobinCall третьими лицами в любых целях.
