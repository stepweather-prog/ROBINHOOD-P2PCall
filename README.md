# 📞 RobinCall v4.1

**Приложение для защищённых P2P-звонков** экосистемы RobinHood P2P.

Облегчённый клиент, сфокусированный исключительно на аудио/видеозвонках с тем же уровнем сквозного шифрования.

---

## 🔐 Безопасность

| Уровень | Технология |
|:---|:---|
| Сигнализация | ECDH P-256 (ключи только на клиенте) |
| Медиа | DTLS-SRTP |
| Верификация | 12-значный Safety Number |
| Хранение | IndexedDB + мастер-пароль (PBKDF2) |
| Блокировка | PIN-код / графический ключ |

---

## 🚀 Как начать

1. Откройте [RobinCall](https://stepweather-prog.github.io/ROBINHOOD-P2PCall/)
2. Нажмите 🏹 — создайте канал
3. Отправьте ссылку собеседнику
4. После подключения нажмите 📞 для звонка

---

## 📋 Возможности

- 📞 Аудиозвонки (P2P через WebRTC)
- 📹 Видео-кружки

- 🔒 Верификация Safety Number
- 🎨 18 тем оформления

---

## 🏗️ Технологии

| Компонент | Назначение |
|:---|:---|
| WebRTC + DTLS-SRTP | Звонки |
| ECDH P-256 | Обмен ключами |
| P2PPong | Сигнальный сервер |
| PWA | Установка на телефон |
